# Credit Card Fraud Detection – End-to-End Data Analytics Project

## 📌 Project Overview

This project analyzes credit card transactions to identify fraudulent transactions and generate actionable business insights.

The project follows an end-to-end data analytics workflow using Python, SQL, Machine Learning, and Power BI.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SQL / MySQL
- Power BI
- GitHub

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. SQL Analysis
6. Machine Learning Fraud Detection
7. Data Visualization
8. Power BI Dashboard
9. Business Insights & Recommendations

## 📊 Dataset Summary

- Total Transactions: 20,000
- Genuine Transactions: 19,661
- Fraudulent Transactions: 339
- Fraud Rate: 1.70%
- Genuine Rate: 98.30%

## 💡 Business Insights

- Fraudulent transactions represent approximately 1.70% of total transactions.
- Although fraud transactions are a small proportion of total transactions, they can create significant financial risk.
- Transaction patterns can be analyzed to identify suspicious behavior.
- Machine learning can support automated identification of high-risk transactions.
- Reducing false positives is important to avoid unnecessarily affecting genuine customers.
- Power BI provides an interactive way to monitor fraud KPIs and trends.

## 💼 Business Recommendations

- Implement automated fraud monitoring.
- Flag high-risk transactions for additional verification.
- Monitor fraud KPIs regularly.
- Use machine-learning predictions to support fraud investigation.
- Continuously update the model using new transaction data.
- Balance fraud detection performance with customer experience.

This project demonstrates how Python, SQL, Machine Learning, and Power BI can be combined to analyze transaction data, detect potential fraud, and generate actionable business insights.
